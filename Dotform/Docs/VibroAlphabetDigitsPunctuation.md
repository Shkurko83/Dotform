# Вибро-алфавит: цифры и пунктуация (черновик, без UI)

Это описание будущего расширения. В текущей версии реализованы только буквы RU/EN и индикаторы EN (`capital`, `number`, `space`) в модели данных.

## Принципы

1. **Ячейка как база** — цифра/знак = стандартный 6-dot паттерн Брайля.
2. **Префикс-индикатор** — перед цифрами: glyph `en.indicator.number` (dots 3-4-5-6) + отдельная haptic-роль `numberIndicator`.
3. **Пунктуация** — отдельный glyph на знак или общий класс + уникальная длительность/число импульсов.
4. **Пробел** — пауза из `instructionPauseDuration` или soft continuous.
5. **Неизвестный символ** — короткий `error` haptic, поток не останавливается.

## Цифры (Grade 1)

| Печать | После # | Точки (как a–j) |
|--------|---------|-----------------|
| 1 | a | 1 |
| 2 | b | 1-2 |
| 3 | c | 1-4 |
| 4 | d | 1-4-5 |
| 5 | e | 1-5 |
| 6 | f | 1-2-4 |
| 7 | g | 1-2-4-5 |
| 8 | h | 1-2-5 |
| 9 | i | 2-4 |
| 0 | j | 2-4-5 |

Релей: `["numberSign","1","2"]` → карточка # + вибро, затем карточки цифр.

## Пунктуация (черновой набор ролей)

- `punctPeriod`, `punctComma`, `punctQuestion`, `punctExclaim`
- `punctColon`, `punctSemicolon`, `punctDash`, `punctQuote`
- `space`, `newLine`, `capitalSign`

## Продуктовый экран (позже)

1. «Вибро-алфавит»: символ → превью ячейки + «Проиграть».
2. Настройки: кастомная вибрация на индикатор числа и на класс/знак пунктуации.
3. Токенизатор релее уже готов к расширению через `GlyphKind`.
