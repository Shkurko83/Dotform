# Спецификация: вибро-алфавит цифр и пунктуации (DotForm Language)

**Статус:** спецификация расширения DotForm Language (цифры, пунктуация, служебные индикаторы).  
**Реализация в UI обучения:** пока не подключена; в модели данных English Grade 1 уже есть индикаторы `capital`, `number`, `space`.  
**Связь с патентным описанием:** документ является частью той же концепции, что и [README](../../README.md): пространственно-зонированная вибрация трёх горизонтальных рядов ячейки Брайля для обучения и передачи текста слепым и слепоглухим пользователям.

---

## 1. Назначение

Буквы DotForm уже описаны в основном README. Для полноценного чтения и передачи текста нужны также:

- **цифры** (0-9);
- **знаки препинания**;
- **служебные индикаторы** (знак числа, признак заглавной буквы, пробел, перевод строки).

Этот документ фиксирует, **как именно** они кодируются в DotForm Language и как должны вести себя уроки и канал «Связь» (релей), когда расширение будет включено в продукт.

Dotform **не заменяет** бумажный Брайль и существующие системы общения. Расширение делает цифровой канал (телефон, часы) пригодным для чисел и знаков тем же тактильным языком, что и для букв.

---

## 2. Базовое правило DotForm (напоминание)

Карточка символа делится на **три горизонтальные зоны**:

| Зона | Точки Брайля |
|------|----------------|
| Верхняя | 1 (слева), 4 (справа) |
| Средняя | 2 (слева), 5 (справа) |
| Нижняя | 3 (слева), 6 (справа) |

| Содержимое зоны | Вибросигнал DotForm |
|-----------------|---------------------|
| Левая **и** правая точка | **Длинный** сигнал |
| Только **левая** | **Один короткий** |
| Только **правая** | **Два коротких** |
| Пусто | **Тишина** (зона пропускается) |

Пользователь при изучении проводит пальцем **сверху вниз**. При потоковой передаче (релей / часы) устройство само воспроизводит ту же последовательность зональных сигналов для каждого символа.

Все глифы ниже (цифры, пунктуация, индикаторы) подчиняются **тому же правилу зон**. Отличие - только набор заполненных точек в ячейке и место символа в потоке текста (префиксы).

## 3. Индикаторы (служебные символы)

Индикаторы сами по себе не «буква» и не «цифра», но меняют смысл следующих ячеек. В DotForm у каждого индикатора есть своя карточка и свой зональный вибропрофиль.

### 3.1. Знак числа `#` (number sign)

| | |
|--|--|
| **ID (EN)** | `en.indicator.number` |
| **Отображение** | `#` |
| **Точки Брайля** | 3, 4, 5, 6 |

Зоны DotForm для `#`:

| Зона | Точки в зоне | Сигнал |
|------|--------------|--------|
| Верх | только 4 | два коротких |
| Середина | только 5 | два коротких |
| Низ | 3 и 6 | длинный |

**Смысл в потоке:** все следующие ячейки до пробела / конца числа / явного сброса трактуются как цифры (см. §4).

**Haptic-роль (настройки):** `numberIndicator` (можно назначить свой паттерн в каталоге сигналов; иначе - зональный DotForm по таблице выше).

### 3.2. Признак заглавной буквы (capital sign) - English Grade 1

| | |
|--|--|
| **ID** | `en.indicator.capital` |
| **Отображение** | `⇧` |
| **Точки** | 6 |
| **Зоны** | низ: только правая (6) → **два коротких**; верх и середина пусты |

**Смысл:** следующая буква читается как заглавная. В русском учебном потоке MVP заглавные могут не требовать отдельного индикатора (карточки уже в верхнем регистре); для EN Grade 1 индикатор обязателен в полной спецификации.

**Haptic-роль:** `capitalSign`.

### 3.3. Пробел

| | |
|--|--|
| **ID** | `en.space` / `ru.space` |
| **Точки** | нет |
| **DotForm** | нет зональных импульсов |
| **Поведение** | пауза длительностью из `instructionPauseDuration` (или доля от неё) **либо** мягкий короткий continuous, если пользователь назначил роль `space` |

### 3.4. Перевод строки

| | |
|--|--|
| **Роль** | `newLine` |
| **Поведение** | как пробел, но пауза длиннее (например ×1.5-2) **или** двойная пауза; отдельная карточка не обязательна |

### 3.5. Неизвестный символ

Короткий сигнал роли `error` (или системный error-haptic). Поток **не останавливается**. Карточка может показать «?» без точек.

## 4. Цифры (0-9)

### 4.1. Правило Брайля Grade 1

Цифры кодируются **теми же точками, что буквы a-j (A-J / а-эквивалент латиницы)**, но **после** знака числа `#`:

| Печать | После `#` соответствует | Точки |
|--------|-------------------------|-------|
| 1 | a | 1 |
| 2 | b | 1, 2 |
| 3 | c | 1, 4 |
| 4 | d | 1, 4, 5 |
| 5 | e | 1, 5 |
| 6 | f | 1, 2, 4 |
| 7 | g | 1, 2, 4, 5 |
| 8 | h | 1, 2, 5 |
| 9 | i | 2, 4 |
| 0 | j | 2, 4, 5 |

Это правило общее для русского и английского учебного Брайля в приложении (цифровой блок не зависит от алфавита букв).

### 4.2. Зональное кодирование DotForm для цифр

| Цифра | Точки | Верх | Середина | Низ |
|-------|-------|------|----------|-----|
| 1 | 1 | один короткий | тишина | тишина |
| 2 | 1, 2 | один короткий | один короткий | тишина |
| 3 | 1, 4 | длинный | тишина | тишина |
| 4 | 1, 4, 5 | длинный | только правая → два коротких | тишина |
| 5 | 1, 5 | один короткий | два коротких | тишина |
| 6 | 1, 2, 4 | длинный | один короткий | тишина |
| 7 | 1, 2, 4, 5 | длинный | длинный | тишина |
| 8 | 1, 2, 5 | один короткий | длинный | тишина |
| 9 | 2, 4 | два коротких | один короткий | тишина |
| 0 | 2, 4, 5 | два коротких | длинный | тишина |

### 4.3. Поток в релее (пример)

Текст `12` токенизируется как:

```
[ numberSign(#), digit1, digit2 ]
```

Воспроизведение:

1. Карточка `#` + вибро зон числа.  
2. Карточка `1` + вибро зон цифры 1.  
3. Карточка `2` + вибро зон цифры 2.

**Haptic-роли (вариант реализации):**

- либо одна роль `digitCell` + обязательный префикс `#`;
- либо отдельные `digit0`…`digit9` для тонкой настройки в каталоге сигналов.

Рекомендация для MVP расширения: **префикс `#` + общий `digitCell` / зональный DotForm по таблице**, без десяти отдельных ролей.

### 4.4. RU / EN

| Скрипт | Цифры |
|--------|-------|
| `russian` | Та же таблица точек; в каталог глифов добавляются `ru.digit.0`…`ru.digit.9` и `ru.indicator.number` (или общие `digit.*` без префикса скрипта) |
| `englishGrade1` | То же; уже заложен `en.indicator.number` |

Идентификаторы в коде могут быть унифицированы как `digit.1`, `indicator.number`, чтобы не дублировать логику.

## 5. Пунктуация

### 5.1. Принцип

Каждый знак - отдельный `BrailleGlyph` с `kind: punctuation`, своими точками Брайля и, следовательно, своим зональным профилем DotForm. В настройках можно:

- оставить **чистый DotForm** по зонам; или  
- назначить **кастомный haptic** на роль знака / на класс «пунктуация».

Ниже - рабочий набор для MVP расширения (точки - по распространённым таблицам Grade 1 / русского Брайля; при расхождении стандартов в локали приоритет у таблицы, зафиксированной в `BrailleCatalog` приложения).

### 5.2. Базовый набор знаков

| Печать | Предлагаемый ID | Точки (6-dot) | Верх | Середина | Низ | Роль haptic |
|--------|-----------------|---------------|------|----------|-----|-------------|
| `.` | `punct.period` | 2, 5, 6 | тишина | длинный | два коротких | `punctPeriod` |
| `,` | `punct.comma` | 2 | тишина | один короткий | тишина | `punctComma` |
| `?` | `punct.question` | 2, 3, 6 | тишина | один короткий | длинный | `punctQuestion` |
| `!` | `punct.exclaim` | 2, 3, 5 | тишина | длинный | один короткий | `punctExclaim` |
| `;` | `punct.semicolon` | 2, 3 | тишина | один короткий | один короткий | `punctSemicolon` |
| `:` | `punct.colon` | 2, 5 | тишина | длинный | тишина | `punctColon` |
| `-` | `punct.dash` | 3, 6 | тишина | тишина | длинный | `punctDash` |
| `«` / `»` / `"` | `punct.quote` | 2, 3, 6 (уточняется локалью) | по таблице точек | | | `punctQuote` |
| `(` / `)` | `punct.parenOpen` / `punct.parenClose` | по каталогу | по таблице | | | `punctParen*` |

> Точные наборы точек для кавычек и скобок в RU и EN могут различаться. При реализации в коде эталон - данные в `BrailleCatalog`; эта спецификация задаёт **метод** (зоны DotForm) и **минимальный набор ролей**.

### 5.3. Класс vs отдельные роли

| Подход | Плюс | Минус |
|--------|------|-------|
| Одна роль `punctuation` на все знаки | Проще настраивать | Хуже различать знаки только «своим» haptic |
| Роль на каждый знак | Максимальная различимость | Много настроек |
| **Рекомендация** | DotForm по зонам по умолчанию + опциональный override на знак | Баланс для слепоглухих |

## 6. Поведение в уроках

Пока UI уроков цифр/пунктуации **выключен**. Когда будет включён:

1. Отдельный блок уровней или раздел «Числа и знаки» после освоения букв.  
2. Карточка глифа на весь экран; проведение пальцем сверху вниз - тот же DotForm.  
3. Для цифр сначала урок на индикатор `#`, затем цифры 1-0.  
4. Для пунктуации - по одному знаку, затем различение пар (`,` vs `.`, `?` vs `!`).  
5. В настройках родителя - включение набора `enabledGlyphIDs` для цифр и знаков (как для букв).  
6. Прогресс ключуется по `glyph.id` (`digit.1`, `punct.comma`, …).

Экран **«Вибро-алфавит»** (справочник):

- список символов с превью ячейки;  
- кнопка «Проиграть» (зональный DotForm или назначенный haptic);  
- подпись «часть DotForm Language».

## 7. Поведение в связи (релей) и на Apple Watch

Токенизатор `TextToHapticEncoder` расширяется:

1. Нормализация текста.  
2. При встрече цифры - вставить `numberSign` (если ещё не в числовом режиме), затем glyph цифры.  
3. При пробеле / букве - сбросить числовой режим.  
4. Знаки препинания - соответствующие punctuation glyphs.  
5. Для EN при необходимости - `capitalSign` перед заглавной.  
6. Неизвестный символ - `error`, без остановки очереди.

На приёмнике для каждого токена:

- показать карточку (для индикаторов - упрощённая карточка с `#` / `⇧`);  
- воспроизвести зональный DotForm **или** назначенный в настройках паттерн;  
- опционально «точки по очереди» (`relayPlayDotsInSequence`);  
- отправить компактный payload на Watch (glyphID, dots, параметры haptic).

Протокол `RelayEnvelope` не меняется: по-прежнему передаётся текст + `scriptID`; расширение - на стороне токенизации и плеера.

## 8. Модель данных (задел в коде)

Уже заложено:

```text
GlyphKind: letter | digit | punctuation | indicator | space
```

English Grade 1:

- `en.indicator.capital` (точка 6)  
- `en.indicator.number` (точки 3-4-5-6)  
- `en.space`

Russian:

- `ru.space`

Планируется добавить:

- `digit.0` … `digit.9` (или `ru.digit.*` / `en.digit.*`)  
- punctuation glyphs из §5  
- роли в `SensoryFeedbackRole` / отдельные ключи настроек для индикаторов и знаков

## 9. Соответствие формуле изобретения

Настоящая спецификация **не вводит новый метод**, а распространяет уже заявленный DotForm Language на цифры, пунктуацию и индикаторы:

- те же три горизонтальные зоны;  
- те же правила длинный / один короткий / два коротких / тишина;  
- те же сценарии обучения по карточке и передачи текста вибропотоком между устройствами (в т.ч. Apple Watch).

Публикация этого файла в открытом репозитории с датированной историей коммитов дополняет описание изобретения для фиксации приоритета разработки.
